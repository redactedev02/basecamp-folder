# Problem solving
 ## Introduction

When learning to program, it is important to be able to solve problems logically and step by step. Problem-solving skills teach you how to tackle a problem before you start writing code.

A flowchart or pseudocode helps you to think through your idea first. This way, you know exactly what your program needs to do, making it easier to actually program it afterwards.

## The assignment: 
- Look ahead to the assignment for week 3: A1W3A2 – Mountain Climbing Time Trial. 
- In week 3, you practiced with flowcharts and pseudocode in class. Now you will apply what you have learned. Create a flowchart or pseudo-code for the assignment. 
- Pay attention to the decisions that need to be made (If) and the actions that may need to be repeated (while loop).
