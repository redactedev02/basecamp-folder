An online retailer sells two products: widgets and gizmos. <br>
Write a program that reads the number of widgets and the number of gizmos in an order from the user. <br>
Then your program should compute and display the total weight of the order.

###### Criteria:
- Each widget weighs 75 grams
- Each gizmo weighs 112 grams

###### Input example:
`Number of widgets: 10`<br>
`Number of gizmos: 1`

###### Output example:
`The Total Weight of the Order: 862 grams`
