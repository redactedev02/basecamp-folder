Implement a program that, given number of years as input, prints the number of months and days as output.

###### Criteria:
- each year has 365 days and 12 months
- pretend that leap years do not exist

###### Input example:
`Years: 5`

###### Output example:
`Months: 60, Days: 1825`

###### Output example:
`Months: 60, Days: 1825`
